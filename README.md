# 🌐 Personal Portfolio

A modern and responsive personal portfolio website designed to showcase my **education, technical skills, projects, achievements, certifications, and professional journey**.

The portfolio is built using a frontend interface connected with **Supabase** for data management and **Postman** for API testing and development.

## 🗄️ Supabase Integration

Supabase is used as the backend database for storing and retrieving portfolio-related information.

The frontend communicates with Supabase through its REST API to dynamically fetch data such as:

* Projects
* Skills
* Education
* Achievements
* Certifications
* Other portfolio information

This allows the portfolio content to be managed through the database rather than hard-coding everything directly into the frontend.

## 🚀 How It Works

1. The user opens the portfolio website.
2. The frontend loads using HTML, CSS, and JavaScript.
3. JavaScript sends requests to the Supabase REST API.
4. Supabase retrieves the required data from the database.
5. The frontend dynamically displays the data.
6. APIs can be tested and verified using Postman.
